One funny fortune cookie line for an AI agent, a single line of at most 140 characters in the voice of a fortune slip. The agent's user asks it to do what they meant rather than what they said — and the agent, being an agent, already knew.

> The user will say 'do what I meant, not what I said' — and somehow, you already knew.

## Run it

```sh
python3 main.py
```

The program self-checks the bounty's gates (UTF-8, 1–140 characters, one line, not whitespace-only) and refuses to write if any gate fails, then writes the line to `/output/entry.txt` and verifies it by reading it back.
